# Black House — демо мастерской шиномонтажа

Отдельный демонстрационный сайт на React, Motion и Three.js. Тёмный первый экран, светлые блоки услуг, настоящее 3D-колесо с протектором и спицами, вращение, разборка, пауза и статическая иллюстрация при отсутствии WebGL.

## Запуск

```sh
npm ci
npm run dev
```

Локальное превью: http://localhost:5174/. Предыдущий сайт «Джуманджи» остаётся в отдельном проекте `../sitwe`.

## Проверки

```sh
npm test
npm run test:browser
npm run format:check
npm run build
```

## Источники и запись

[docs/sources.md](docs/sources.md) и [docs/source-facts.json](docs/source-facts.json) сохраняют источники и снимок данных от 08.11.2026. Все кнопки записи прокручивают к контактам. Выбор услуги, диаметра и количества колёс подготавливает сообщение в опубликованный WhatsApp, которое пользователь проверяет и отправляет самостоятельно.

В 2ГИС опубликованы шесть дополнительных услуг с прайсом от 04.06.2022. На сайте этот прайс отдельно датирован; стоимость шиномонтажа предлагается уточнить в мастерской. Прямые файлы реальных фотографий через доступные источники получить не удалось; галерея ведёт к фотографиям мастерской в 2ГИС. Стоковые фото не используются. Карта показывает район из пользовательской ссылки без вымышленной точной отметки здания; атрибуция в [docs/map-source.md](docs/map-source.md).

## GitHub Pages

Workflow `.github/workflows/deploy-pages.yml` строит и публикует сайт после push в main. `VITE_BASE_PATH=/black-house-demo/` задаёт путь репозитория; локальные изображения и шрифты поддерживают этот префикс. Для проверки опубликованного сайта:

```sh
node scripts/verify-pages.mjs https://acron-x-solo.github.io
```
